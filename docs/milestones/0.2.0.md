# Milestone 0.2.0: Expanded Portfolio Citadel

## Outcome

Prove the complete CommitQuest interaction language with a provider-independent history campaign before accepting arbitrary repository input.

## Acceptance criteria

- The bundled projection independently versions its schema, mapping algorithm, and scoring ruleset.
- Six meaningful repository regions form a navigable Phaser world map.
- Angular provides keyboard-accessible views for the map, candidate quests, encounters, and chapters.
- Eight roadmap items appear only as repository-authored candidate quests.
- Merged pull requests appear as verified historical encounters with primary evidence links.
- Releases appear as source-linked chapters with exactly one current chapter.
- The fixture continues working without authentication, persistence, GitHub availability, or AI.
- Desktop and mobile layouts expose the same evidence and controls.
- Formatting, lint, accessibility rules, tests, and production build pass in CI.

## Excluded

- Arbitrary repository URL input
- Runtime GitHub API calls
- Java API, authentication, database, queue, or cloud infrastructure
- Scoring changes or AI-generated campaign state
