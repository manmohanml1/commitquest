# CommitQuest 0.1.0 release record

## Outcome

The demo-first vertical slice proves that a real repository can be translated into an attractive, playable campaign without requiring authentication, live GitHub access, persistence, or AI.

## Accepted scope

- Branded landing experience and product explanation
- Sanitized Portfolio Citadel fixture with independent schema, mapping, and scoring versions
- Lazy-loaded Phaser map with four selectable repository regions
- Keyboard-accessible Angular controls and source-linked evidence panel
- Verified repository metrics: 13 merged pull requests, 13 releases, two workflow files, and eight planned roadmap candidates
- Desktop and 390×844 responsive layouts with reduced-motion support
- Social-card asset and production metadata
- Monorepo structure prepared for the later Java 25/Spring Boot API boundary
- Repeatable Node 24 quality gate and GitHub Actions workflow

## Verification

Run `npm run verify` from the repository root. The gate enforces formatting, zero-warning static analysis, unit tests, Angular template accessibility rules, and the optimized production build.

Browser acceptance was completed against `http://localhost:4200/` with no console errors. The Portfolio Citadel region controls update the evidence projection and link to the exact primary GitHub evidence.

## Deliberately excluded

Live repository analysis, authentication, persistence, GitHub credentials, webhooks, server infrastructure, and AI begin in later roadmap milestones and are not required for this release.
