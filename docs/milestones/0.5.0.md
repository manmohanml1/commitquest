# Milestone 0.5.0: Connected repositories and dual design modes

**Status:** Planned. Design and authorization contracts accepted; implementation has not begun.

## Outcome

A signed-in user can install the minimum-permission CommitQuest GitHub App for selected repositories and use a fully redesigned authenticated workspace in either Modern or Chronicle mode. Both modes expose the same evidence, ownership, permissions, campaign actions, and accessibility semantics.

## Scope

### GitHub App connection

- [ ] Register and document a dedicated GitHub App separate from GitHub OAuth identity.
- [ ] Request only the repository permissions required by the accepted evidence contract.
- [ ] Support selected-repository installation, installation reconciliation, suspension, revocation, and permission changes.
- [ ] Keep private-repository evidence private and owner scoped.
- [ ] Distinguish unavailable, unauthorized, removed, private, and unknown provider states.
- [ ] Add tenant, installation, repository-selection, and permission-boundary tests.

### Authenticated product redesign

- [ ] Approve shared signed-in information architecture and responsive wireframes.
- [ ] Move signed-in work from the extended public landing page into a dedicated application shell.
- [ ] Redesign campaign switching, realm overview, world, quest log, chronicle, vault, connection, account, and destructive-data flows.
- [ ] Preserve the v0.4 public preview, saved-campaign behavior, evidence provenance, and security boundaries.
- [ ] Make the one recommended next engineering action clear without implying that v0.5 has introduced scoring.

### Two complete design modes

- [ ] Ship a redesigned Modern mode for focused engineering work.
- [ ] Ship an original medieval-fantasy Chronicle mode using illuminated-manuscript, heraldic, ledger, and map-table motifs.
- [ ] Implement both through shared semantic components and versioned design tokens rather than duplicated page trees.
- [ ] Persist the user's choice and preserve route, campaign, and working state across a mode switch.
- [ ] Give decorative typography an easy-read alternative and support reduced motion, forced colors, keyboard navigation, zoom, and reflow.
- [ ] Pass functional and visual-regression matrices for both modes on desktop and mobile.

## Non-goals

- No webhook-driven synchronization; that remains v0.6.
- No evidence score, health grade, unlock economy, or inventory; those remain v0.7.
- No public showcase or portfolio embed; those remain v0.8.
- No copied game artwork, UI assets, proprietary fonts, layouts, characters, or trademarks.
- No paid hosting dependency, AI-authored achievement, repository write permission, billing, or team surveillance.

## Design source

The binding visual, architecture, originality, accessibility, and regression contract is [Modern and Chronicle design modes](../product/DESIGN_MODES.md).

## Release rule

Checkbox completion, a merge, or a deployment does not authorize a `v0.5.0` tag or GitHub Release. Release actions always require a separate explicit owner instruction.
