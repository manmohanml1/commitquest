# Milestone 0.3.0: Public repository preview

**Status:** Implementation complete locally; hosted API deployment and release review remain.

## Outcome

Let a visitor paste one public GitHub repository URL and receive an ephemeral CommitQuest campaign projection without creating an account or connecting a GitHub App.

## Acceptance criteria

- The web accepts only a supported public GitHub HTTPS repository URL and explains validation failures accessibly.
- A Java 25/Spring Boot 4 API is the sole GitHub boundary; the browser receives no provider credential or provider-native payload.
- The API validates and normalizes the repository identity before performing bounded provider work.
- GitHub transport DTOs terminate inside the provider adapter and are mapped to immutable provider-neutral evidence.
- The API returns a deterministic, independently versioned campaign projection compatible with the released web projection contract.
- Invalid, not found, private, rate-limited, unavailable, and incomplete repositories produce distinct, actionable states.
- Preview data is request-scoped and ephemeral; no repository evidence or campaign state is persisted.
- The bundled Portfolio Citadel campaign remains available when GitHub or the API fails.
- Desktop and mobile expose equivalent input, progress, result, evidence, fallback, and retry behavior.
- Domain mapping has unit tests; provider adapters have fixture-based contract tests; architecture tests enforce module and provider boundaries; the web/API journey has automated regression coverage.
- Formatting, zero-warning lint, tests, architecture checks, and production builds pass in CI.

## Operational limits

- One repository per request.
- Only public GitHub repositories are supported.
- Provider requests, pages, payload size, and request duration are explicitly bounded.
- Rate-limit metadata is observed and translated without leaking credentials or sensitive headers.
- Logs contain correlation and repository identity metadata but never credentials or unfiltered provider payloads.

## Excluded

- Authentication, user accounts, or saved campaigns
- PostgreSQL, Flyway, jOOQ, Redis, queues, workers, or webhooks
- GitHub App installation or private repository access
- Repository writes, automated issue or pull-request actions
- AI-generated or AI-mutated campaign state
- Public showcase publishing or portfolio embeds
